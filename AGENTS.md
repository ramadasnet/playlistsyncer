# PlaylistSyncer Web App

Web app that allows registered users to sync their playlists among multiple music providers.

## Stack

- TypeScript + Nuxt + MongoDB, running with Bun.
- Production is hosted in AWS, using Mongo Atlas as the database, running behind Cloudflare.
