# Code Style

Use the following Prettier rules:

```
{
    "trailingComma": "none",
    "tabWidth": 4,
    "semi": false,
    "singleQuote": false,
    "arrowParens": "always",
    "bracketSpacing": false,
    "printWidth": 250
}
```

- When creating new files, keep the same style and patterns as the existing source code for the repo in use.
